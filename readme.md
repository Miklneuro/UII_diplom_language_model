Привет! Этот репозиторий посвящен отчету об обучении модели GPT-3 RU программированию в рамках дипломного проекта Университета Искусственного Интеллекта (УИИ). В проекте использовались методы создания датасетов на основе книг, анализ коллекции Jupyter Notebook и различные методы генерации синтетических датасетов согласно созданному тематическому плану. Проект был успешно сдан в 2025 году.
Hi there! This repository is dedicated to a report on training the GPT-3 RU model for programming as part of a diploma project at the University of Artificial Intelligence (UAI). The project utilized methods for creating datasets from books, analysis of a collection of Jupyter Notebooks, and various techniques for generating synthetic datasets according to a developed thematic plan. The project was successfully completed in 2025.
